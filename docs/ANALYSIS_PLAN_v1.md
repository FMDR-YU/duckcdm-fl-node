# 분석계획 v1 (사전 지정, 2026-10-10)

이 문서는 SNUH 실자료 분석(P4 행렬 생성 이후의 모든 모델 학습과 심사)을 시작하기 전에 고정한다. 고정 시점은 이 문서가 처음 커밋된 시점(`git log -- docs/ANALYSIS_PLAN_v1.md`)이다. 이후 바꾸는 내용은 `docs/ANALYSIS_DEVIATIONS.md`에 날짜와 이유를 적고, 논문에는 사전 지정과 변경을 구분해 쓴다. 가설 1–4는 IRB 계획서(2026-10-06 제출), 가설 5는 변경계획서 v1.1(`IRB/v1.1_변경심의/EGRESS_연구계획서_v1.1_서식5.docx`)과 같다. 구현 근거는 `analysis/snuh_pilot/`.

## 1. 비교 대상(반출 경로)과 모델

| 기호 | 경로 | 학습 자료 |
|---|---|---|
| A_x (코드 `A_0`) | 중앙 | 훈련 행 전부 |
| A′ (`Aprime_0`) | 크기 대조 | 기관 하나와 같은 크기의 무작위 부분표본 |
| B_k (`B1_k`, `B2_k`) | 기관별 | 가상 기관 k의 행만 |
| B_comb (`B1_comb`, `B2_comb`) | 예측평균 | 세 기관 모델 예측의 평균 |
| F (`F_B1`, `F_B2`) | 연합 | FLARE 히스토그램 수평 XGBoost, 세 기관 |

- 주 모델 계열은 XGBoost 단일 모델(`xgb_krcp`, `xgb_leaky`, `xgb_regularized`; 하이퍼파라미터는 `pilot_lib._xgb_kwargs`). 게재 모델 구조의 소프트 보팅 4모델 앙상블(`krcp`, `leaky`, `regularized`)은 SNUH 보조분석이다(F는 앙상블로 만들 수 없다).
- 가상 기관: B1 균등 3개, B2 50/30/20%. CDM 경로(`--tag cdm`)에서는 고정 물리 분할(B1·B2 한 벌, 시드마다 같음).
- 자료: v205 코호트, 36변수, 결과변수는 변경심의 초안 확인 1번에서 확정한 정의. 훈련/검증 분할은 게재 분할(70/30, random_state 42). 검증 행은 어떤 모델의 학습에도 쓰이지 않는다. 연합 작업에서는 기관마다 공통 검증 행의 3분의 1이 모니터링용 파일로 들어 있으나 조기 종료를 쓰지 않으므로(`early_stopping_rounds=0`) 학습에 영향이 없고, 보고하는 성능은 연합 밖에서 공통 검증셋 전체로 계산한다.
- 반복: 시드 42–51(10회). 시드는 모델 시드와 (고정 분할이 아닐 때) 분할을 바꾼다.

## 2. 지표

- 효용: 공통 검증셋 AUROC. 경로 간 차이는 같은 검증 행에서의 쌍체 부트스트랩(1,000회) 95% 구간과 시드 간 t 구간.
- 노출(Gate 2, 멤버십 추론): shadow-model 공격 AUC(주), loss-threshold AUC, 온라인 LiRA AUC, TPR@1% FPR. shadow 64개(공격자 모델, 자료 전체에서 무작위 부분집합), shadow-model 공격은 그중 16개. 평가 표본은 회원과 비회원을 같은 수로 뽑은 균형 표본. 하위집단 지표는 평가 표본에서 100명 이상인 집단만.
- 판정: Gate 2는 shadow-model AUC ≤ 0.55면 통과, 0.50–0.60 민감도 표를 함께 낸다. 이 값은 수행한 공격에 대한 하한이다.
- 보고 억제: 개수 11 미만은 `<11`, 행·ID·원값·자유텍스트는 쓰지 않는다.

## 3. 가설과 판정 규칙

| 가설 | 내용 | 판정 규칙 |
|---|---|---|
| H1 | 심사는 과적합 모델과 정규화 모델을 구별한다 | `leaky`의 shadow AUC 시드 평균이 0.55 초과(차단), `regularized`는 0.55 이하(통과), 통과 모델 AUROC ≥ 차단 모델 AUROC |
| H2 | 기관별 모델의 노출은 중앙보다 높다. 차이의 대부분은 표본 크기다. 기관 구성이 불균형할수록 크다 | (기관 평균 − A_x)의 시드 t 구간 하한 > 0. 크기 설명 몫 = (A′ − A_x)/(기관 평균 − A_x) ≥ 0.5. (B2 격차) > (B1 격차) |
| H3 | 예측평균 모델의 효용은 중앙 대비 비열등 | ΔAUROC(B_comb − A_x) 시드 t 구간 하한 > −0.02 |
| H4 | 포맷과 재현성 | Gate 1: 검증 행 예측 최대 차 < 10⁻⁶. Gate 3: 서명·자료 해시 일치, \|ΔAUROC\| ≤ 10⁻⁴. F는 같은 작업을 새 작업공간에서 다시 돌려 \|ΔAUROC\| ≤ 10⁻⁴, 예측 최대 차 < 10⁻⁶ |
| H5 (주 가설) | 연합 모델은 중앙 대비 효용이 비열등이고 노출이 중앙과 같은 수준이며 기관별보다 낮다 | ΔAUROC(F − A_x) 시드 t 구간 하한 > −0.02 **그리고** shadow AUC(F) ≤ shadow AUC(A_x) + 0.01 **그리고** (기관 평균 − F)의 시드 t 구간 하한 > 0. 세 조건이 모두 맞아야 지지 |
| H6 | 노출은 훈련 크기에 따라 줄어든다 | 크기별(2천, 5천, 1만, 훈련 전체) shadow AUC에 대해 시드 평균의 순위상관(Spearman) < 0이고 크기-노출 직선 기울기의 구간 상한 < 0 |

판정은 `analysis/snuh_pilot/06_summarize.py`가 계산한다(요약의 "Pre-specified decision rules" 절, 눈으로 읽어 판정하지 않는다). 위 표가 열어 둔 부분은 다음과 같이 정했다. H1은 중앙 모델(A_x)에서 판단한다. H2는 두 부분을 따로 판정한다. B1 부분은 (기관 평균 − A_x)의 하한 > 0이고 크기 몫 (A′ − A_x)/(B1 격차) ≥ 0.5이며, B2 부분은 (B2 기관 평균 − A_x)의 하한 > 0이고 B2 격차 > B1 격차다. H3은 B1_comb과 B2_comb을 따로 판정한다. H4는 Gate 1, Gate 3, 연합 재실행의 세 부분을 모두 만족해야 한다. H5는 시나리오(B1, B2)와 변형마다 따로 판정하고 F가 있는 시드만 쓴다. 입력이 없거나 시드가 둘 미만이면 "not evaluable"로 표시한다. 조건 하나가 실패하면 다른 조건을 평가할 수 없어도 "not supported"다. H4의 Gate 3는 변형마다 중앙 모델(A_x, 시드 42)에 대해 실행하며, 어느 변형에든 Gate 1 또는 Gate 3 행이 없으면 그 변형의 H4는 "not evaluable"이다.

B_comb(예측평균)는 평균 예측기를 블랙박스로 보고 공격한다. 세 구성 모델이 파일로 함께 반출되면 노출은 가장 노출된 구성 모델 이상이므로, 반출 결정에 쓰는 값은 B_k 행이고 B_comb 행은 평균 예측기만 공개할 때의 노출이다. 보고에서는 둘을 함께 싣고 해석에서 구분한다.

**주 판정과 보조 판정(2026-10-11 검토에서 확정).** 주 판정은 둘이다: H5의 krcp F_B1(출판 설정, 균등 3기관)과 H2의 B1 부분(krcp). 나머지는 모두 보조다: regularized와 leaky 설정, B2 시나리오, H1, H3, H4, H6. 초록과 본문에서 H3과 H6의 대표로 인용하는 판정은 krcp다(H3은 B1_comb). 요약표의 `role` 열이 이 구분을 보여 준다. 모든 사전 지정 분석은 판정과 상관없이 보고한다. 중간 분석은 하지 않고, 판정이 불리하다는 이유로 시드를 늘리거나 설정을 바꾸지 않는다.

H5의 중앙 대비 노출 한계 0.01은 이 계획에서 처음 정한 값이다(IRB 문안은 "같은 수준"). 판정 공격은 shadow-model AUC이고(IRB 문안), LiRA AUC, LiRA TPR@1% FPR, loss AUC에서의 경로 − 중앙 차이는 판정 규칙이 아니라 기술 통계로 보고한다(요약의 "Exposure relative to the central model" 표). 구간이 0을 제외하면 그대로 본문에 쓴다. B_comb의 노출이 중앙보다 낮은지는 가설이 아니라 탐색적 보고다. 가설별로 따로 판정하며 다중성 보정은 하지 않는다. 시드가 10개뿐이어서 구간은 넓고, 방향이 일치하는지를 우선 본다. 시드 구간은 고정된 코호트와 훈련/검증 분할 안의 변동(모델 난수, 공격 표본, shadow 추출)을 반영하며 코호트의 표본 변동은 포함하지 않는다. 이 점은 논문의 한계에 쓴다.

## 4. 주요 가지

- 설정 3종: krcp(게재 설정), leaky(과적합), regularized(정규화). 중앙·기관별·예측평균은 3종 모두, F는 krcp와 regularized로 시드 10개 전부 돌리고 leaky는 양성 대조로 시드 42의 B1에서 한 번만 돌린다(연합 학습 비용이 크다). 보고의 중심은 krcp와 regularized이고 leaky는 H1의 양성 대조다.
- 서브샘플링이 없는 `plain` 설정의 F와 A_x 동일성(예측 최대 차 < 10⁻⁶)은 연합 구현의 점검이며 가설 검정이 아니다.
- 민감도: 임계 0.50–0.60, shadow 수 8·16·64, B1/B2 각각, 하위집단(연령 65세, 성별, 당뇨, CKD 병기), 앙상블 계열(SNUH).
- SynPUF는 같은 틀의 개발·재현용이며 가설 판정에는 쓰지 않는다(부록). MIMIC-IV-ED는 SNUH 일정이 어긋날 때 쓰는 보험이다. 그때는 이 계획에 자료 정의(코호트, 변수, 기관 분할)만 덧붙인 부록을 실행 전에 커밋한다.

## 5. 이 계획이 아닌 것

- 최종 모델의 임상 성능 개선 주장, 안전 보증, 학습 중 통계(히스토그램)의 프라이버시 평가는 하지 않는다.
- 수행하지 않은 공격(속성 추론, 모델 복원 등)에 대한 결론은 내지 않는다.
